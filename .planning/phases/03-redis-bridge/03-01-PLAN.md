  <implementation>
    Create hackrf_ros/redis_bridge.py with RedisBridge class following RESEARCH.md Pattern 1
    exactly. Key implementation decisions (all from RESEARCH.md and CONTEXT.md):

    1. IMPORTS: queue, threading, time, json, numpy as np, redis
       (no rclpy imports — independently testable per D-10)

    2. CLASS CONSTANTS (RED-05 / D-12):
       STREAM_KEY = 'hackrf:iq:stream'
       STATE_KEY  = 'hackrf:state'
       CMD_KEY    = 'hackrf:cmd'

    3. __init__(self, iq_queue, node, logger, maxlen=10000):
       Store all args. _redis = None. _stop_event = threading.Event().
       _thread = None. _state_lock = threading.Lock().

    4. open() -> bool (D-01, D-02):
       redis.Redis(host='localhost', port=6379, decode_responses=False)
       .ping() — catch redis.exceptions.ConnectionError → log warning, return False.
       On success: clear _stop_event, start daemon thread named 'redis_bridge', return True.

    5. close() -> None:
       _stop_event.set(). Thread is daemon, no join required.

    6. needs_reconnect @property:
       return self._stop_event.is_set() and self._thread is not None

    7. publish_state(state: dict) -> None (RED-02 / D-09, D-11):
       Guard: if self._redis is None: return.
       Acquire _state_lock. Call self._redis.hset(STATE_KEY, mapping={k: str(v) for k,v in state.items()}).
       Catch redis.exceptions.RedisError → logger.warning.
       NOTE: redis-py ConnectionPool is thread-safe; _state_lock guards against
       concurrent publish_state() calls only, not against bridge thread XADD.

    8. _bridge_loop() -> None (RED-04 / D-11):
       last_cmd_id = b'$'  # only new commands (RESEARCH.md Pitfall 3 — CORRECT behavior)
       while not _stop_event.is_set():
           _drain_iq_queue()
           last_cmd_id = _poll_commands(last_cmd_id)  # CRITICAL: capture return value (Pattern 3)

    9. _drain_iq_queue() (RED-01):
       Non-blocking loop: queue.get_nowait() until queue.Empty → break.
       For each chunk: call _xadd_iq(chunk).

    10. _xadd_iq(chunk: bytes) (RED-01, D-03):
        Convert int8 → float32:
          iq = np.frombuffer(chunk, dtype=np.int8).reshape(-1, 2)
          float32_arr = np.empty(len(iq) * 2, dtype=np.float32)
          float32_arr[0::2] = iq[:, 0].astype(np.float32) / 128.0  # I
          float32_arr[1::2] = iq[:, 1].astype(np.float32) / 128.0  # Q
        self._redis.xadd(STREAM_KEY, {b'data': float32_arr.tobytes()},
                         maxlen=self._maxlen, approximate=True)
        On RedisError: logger.warning, _stop_event.set() to trigger reconnect detection.

    11. _poll_commands(last_id: bytes) -> bytes (RED-03):
        results = self._redis.xread({CMD_KEY: last_id}, count=10, block=200)
        On RedisError: logger.warning, _stop_event.set(), return last_id.
        If no results: return last_id.
        For each entry: parse JSON from fields[b'cmd'], call _dispatch_command(cmd).
        Advance last_id to entry_id. Return last_id.
        On json.JSONDecodeError or UnicodeDecodeError: logger.warning, continue.

    12. _dispatch_command(cmd: dict) (RED-03 / D-06):
        Module-level dict _COMMAND_HANDLERS maps action names to lambda(node, params).
        Handlers call node methods:
          'setfreq'          → node._set_center_frequency(p['freq_hz'])
          'set_sample_rate'  → node._set_sample_rate(p['sample_rate'])
          'set_lna_gain'     → node._set_lna_gain(p['lna_gain'])
          'set_vga_gain'     → node._set_vga_gain(p['vga_gain'])
          'set_amp_enabled'  → node._set_amp_enabled(p['enabled'])
          'appstart'         → node._mayhem.appstart(p['app_name'])
          'serial_setfreq'   → node._mayhem.setfreq(int(p['freq_hz']))
          'start_rx'         → node._start_rx_if_stopped()
          'stop_rx'          → node._stop_rx_if_running()
        Unknown action: logger.warning('RedisBridge: unknown command action: ...')
        Dispatch errors: catch Exception → logger.error(f'command {action!r} failed: {e}')

    ANTI-PATTERNS TO AVOID (from RESEARCH.md):
    - decode_responses=False is REQUIRED (binary IQ data)
    - block=0 MUST NOT be used (use block=200 so _stop_event is checked)
    - Starting XREAD with '0' MUST NOT be used (use b'$' for new-only)
    - Redis connection MUST be created once in open(), not per-call
  </implementation>
