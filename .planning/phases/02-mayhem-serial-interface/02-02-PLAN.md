Serial open pattern (pyserial 3.5 — pass port=None to constructor, set .port, call .open()):
```python
import serial
ser = serial.Serial()
ser.port = '/dev/ttyACM1'
ser.baudrate = 115200   # USB ACM ignores baud rate; required non-zero
ser.timeout = 1.0       # readline() returns after 1s even with no newline
ser.write_timeout = 2.0
ser.open()
```

_send_command() contract (from 02-RESEARCH.md Pattern 1):
- Acquire _serial_lock before writing
- Drain _response_queue of stale data before sending
- Write f"{cmd}\r\n".encode('utf-8')
- Collect lines from _response_queue until line.startswith('ch>') is seen
- Skip lines that equal cmd (command echo from ChibiOS)
- Raise TimeoutError if deadline exceeded
- Return list of non-echo, non-prompt lines

ChibiOS prompt detection:
- Line starts with 'ch>' — signals end of response
- The prompt may have leading whitespace; use line.lstrip().startswith('ch>')

applist response format (one app per line):
  "<short_name> <full_name> <category>"
  Parse: short_name = line.split()[0]

radioinfo response format (key: value lines):
  "freq: 433920000"
  "bandwidth: 1750000"
  Parse: k, _, v = line.partition(':')

Reconnect signal:
  _stop_event.set() in _reader_loop on SerialException — HackRFNode checks this to schedule reconnect
</interfaces>

Pitfalls (from 02-RESEARCH.md):
- Never issue the 'hackrf' serial command (destroys ACM interface)
- Never parse by fixed line count — only the ch> prompt is a reliable terminator
- Add brief sleep or readiness event after thread.start() before first command (Pitfall 4)
- _serial_lock must be acquired in _send_command, not in each public method individually
</context>

Key implementation requirements:
1. **Constructor**: `__init__(self, port: str, logger, timeout: float = 3.0)` — store port, logger, timeout. Initialize `_serial = serial.Serial()` with `serial.Serial()` (no port arg), set `.port`, `.baudrate=115200`, `.timeout=1.0`, `.write_timeout=2.0`. Do NOT call `.open()` in `__init__`.
2. **open()**: Call `self._serial.open()`, clear `_stop_event`, start daemon `_reader_thread`. Add `time.sleep(0.05)` after `thread.start()` to avoid Pitfall 4 (command before thread ready). Return True on success, False on SerialException.
3. **close()**: Call `_stop_event.set()`, then `self._serial.close()` if open.
4. **_reader_loop()**: `while not _stop_event.is_set()` — call `self._serial.readline()`, decode with `errors='replace'`, strip, put non-empty lines to `_response_queue`. On `serial.SerialException`, log error and set `_stop_event`.
5. **_attempt_send(cmd) -> list[str]**: Private helper that performs one write+collect cycle (no retry logic). Drain `_response_queue` (while not empty: get_nowait). Write `f"{cmd}\r\n".encode('utf-8')`. Loop with `deadline = time.monotonic() + self._command_timeout`: get from `_response_queue(timeout=0.1)`, skip if `line == cmd` (echo), break if `line.lstrip().startswith('ch>')`, else append to lines. Raise `TimeoutError` if deadline exceeded. Return collected lines. The `_serial_lock` is NOT acquired inside this helper — the caller holds it.
6. **_send_command(cmd) -> list[str]**: Acquire `_serial_lock`. Call `_attempt_send(cmd)`. If `TimeoutError` is raised: log `self._logger.warning(f"Command '{cmd}' timed out, retrying once")`, then call `_attempt_send(cmd)` again. If the retry also raises `TimeoutError`, let it propagate to the caller. Return lines on success. (per D-12: garbled/incomplete responses logged as warnings and retried once before returning error.)
7. **query_applist()**: Call `_send_command('applist')`. Parse each line: `short_name = line.split()[0]` for non-empty lines. Store in `self._known_apps`. Return list.
8. **appstart(short_name)**: `_send_command(f'appstart {short_name}')`. Return `not any('error' in l.lower() for l in lines)`.
9. **setfreq(freq_hz: int)**: `_send_command(f'setfreq {freq_hz}')`. Return `not any('error' in l.lower() for l in lines)`.
10. **radioinfo()**: `_send_command('radioinfo')`. Parse `key: value` lines with `line.partition(':')`. Return dict with `k.strip().lower(): v.strip()`.
