<objective>
Offload the blocking stop_rx / start_rx sequence from the ROS2 executor thread to a background daemon thread.

Purpose: `sample_rate` changes in `_param_callback` currently call `stop_rx()` then `start_rx()` with up to 500 ms of blocking time (including three retry sleeps). This runs inside the ROS2 executor thread, stalling all timer callbacks — including PSD publishing and the diagnostics updater — for that duration.

The fix: `_param_callback` enqueues work onto a `queue.Queue` and returns immediately. A long-lived daemon thread (`_param_worker`) drains the queue and executes the stop/start sequence under `_device_lock` without touching the executor thread.

Output:
- `_param_queue: queue.Queue` instance variable (bounded, size 4)
- `_param_worker_thread: threading.Thread` daemon started in `on_activate`
- `_param_callback` reduced to: validate ranges → put work on queue → return `SetParametersResult(successful=True)`
- `_param_worker()` method: loop that drains queue, applies hardware changes with retry logic
- Existing retry logic (three attempts with 0.15/0.3/0.5 s sleeps) preserved — just moved to worker thread
- `test/test_async_param.py` with source-level assertions
</objective>

       def _param_worker(self) -> None:
           """Background thread: applies parameter changes to HackRF hardware (REL-02).

           Drains _param_queue. Sentinel value None causes thread to exit.
           Retry logic for stop_rx/start_rx lives here — NOT in the executor thread.

           while True:
               try:
                   item = self._param_queue.get(timeout=1.0)
               except queue.Empty:
                   continue
               if item is None:   # shutdown sentinel
                   break
               pending, needs_restart = item
               with self._device_lock:

                       try:

                       self._apply_pending(pending)
                   if needs_restart and not self._is_streaming and self._hackrf is not None:
                       for attempt, settle in enumerate([0.15, 0.3, 0.5]):

                           try:
                               self._hackrf.start_rx(self._rx_callback)

| _param_worker thread → hardware | worker holds _device_lock for all hardware access, same as other code paths |
