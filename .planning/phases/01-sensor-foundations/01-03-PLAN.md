<!-- CFAR formula from wiki -->
CA-CFAR threshold multiplier (Holik eq 11.39):
  M = 2 * n_train  (total reference cells)
  T_m = M * (Pfa ** (-1/M) - 1)

Sliding noise estimate kernel (matches target-detection-modeling.md §7.1):
  kernel = np.zeros(2*(n_train + n_guard) + 1)
  kernel[:n_train] = 1.0
  kernel[-n_train:] = 1.0
  kernel /= M
  mu = convolve1d(psd_linear, kernel, axis=-1, mode='nearest')
  detections_mask = psd_linear > (T_m * mu)

Two-pass adaptive guard (per D-02):
  Pass 1: guard=guard_cells (8), find initial bin clusters
  Pass 2: for each cluster, set guard = max(guard_cells, cluster_width_bins//2 + 2)
          rerun cfar for that CUT with wider guard; validate cluster still detected

Signal clustering (per DET-02):
  from scipy.ndimage import label
  labeled, n_clusters = label(detections_mask)
  for cluster_id in range(1, n_clusters + 1):
      bin_indices = np.where(labeled == cluster_id)[0]
      # power-weighted centroid frequency
      # 3 dB bandwidth = freq span of bins above (peak_power - 3 dB)
      # integrated power = sum of linear power in bins * bin_width

Detection ID assignment (per D-04, DET-04):
  freq-proximity matching: if new centroid is within 0.5 * bandwidth of existing ID center,
  inherit that ID; update center to power-weighted average; otherwise assign next ID.
  IDs are uint32, monotonically increasing from 1.
  Persistence: increment frame_count[id] each frame signal detected.
  Decay: if signal absent, decrement (or count absence frames); remove after N_decay frames.
  Publish only detections with persistence_frames >= persistence_n.

Band classification lookup table (per D-10, D-11, DET-05, DET-06):
  ~30 entries covering: WiFi 2.4G (2.4-2.4835 GHz, BW~20 MHz), WiFi 5G (5.15-5.85 GHz, BW~20-80 MHz),
  BLE/Bluetooth (2.4-2.4835 GHz, BW~1-2 MHz), ZigBee (2.4-2.4835 GHz, BW<1 MHz),
  LTE Band 2 (1850-1990 MHz), LTE Band 4 (1700-2100 MHz), LTE Band 7 (2500-2700 MHz),
  LTE Band 12 (699-746 MHz), LTE Band 13 (746-787 MHz), LTE Band 66 (1710-2200 MHz),
  ISM 900 (902-928 MHz, BW<500 kHz), ISM 2400 (2.4-2.5 GHz generic),
  FM Radio (87.5-108 MHz, BW~200 kHz), GPS L1 (1575.42 MHz ±1 MHz),
  DECT (1880-1900 MHz), CDMA (824-894 MHz).
  Heuristic override: BW>15 MHz in 2.4G ISM → wifi_2_4g; BW<2 MHz → ble or zigbee.
  Fallback: 'unknown'

```python
"""CA-CFAR RF Detection Node.

Subscribes to /hackrf/spectrum (SpectrumStamped), runs CA-CFAR energy detection,
groups adjacent bins into signal clusters, applies persistence tracking and band
classification, publishes RFDetectionArray and RFEnvironment.
"""
from __future__ import annotations
import time
import numpy as np
from scipy.ndimage import convolve1d, label as ndimage_label
import rclpy
from rclpy.node import Node
from rclpy.qos import QoSProfile, ReliabilityPolicy, HistoryPolicy
from rclpy.callback_groups import ReentrantCallbackGroup
from hackrf_interfaces.msg import (
    SpectrumStamped, RFDetection, RFDetectionArray, RFEnvironment)
```

**`_ca_cfar(psd_db, guard, train, pfa)` method:**
- Convert psd_db (dB) to linear: `psd_lin = 10.0 ** (psd_db / 10.0)`
- Build sliding kernel: zeros array of length `2*(train+guard)+1`; first `train`
  slots = 1/M, last `train` slots = 1/M; guard and CUT slots = 0; M = 2*train
- `mu = convolve1d(psd_lin, kernel, mode='nearest')`
- `T_m = M * (pfa ** (-1.0 / M) - 1.0)` — Holik eq 11.39
- Return `psd_lin > (T_m * mu)` (boolean mask)

**Two-pass adaptive guard (D-02):**
- Pass 1: run `_ca_cfar(psd_db, guard=self._guard, train=self._train, pfa=self._pfa)`
- Use `ndimage_label` to find initial clusters
- Pass 2: for each cluster wider than `2*self._guard` bins, expand guard to
  `cluster_width // 2 + 4`, rerun cfar for the CUT range only if needed.
  Simplification: only rerun on clusters wider than `4 * self._guard` bins.
  For Phase 1, Pass 1 with empirically chosen guard=8 is sufficient; two-pass
  refinement can be added in place without breaking the interface.

**`_group_detections(mask, psd_db, bin_width_hz, center_freq_hz)` method:**
- `labeled, n = ndimage_label(mask)`
- For each cluster 1..n:
  - `bins = np.where(labeled == cid)[0]`
  - Compute frequency axis: `freqs = (bins - len(psd_db)//2) * bin_width_hz + center_freq_hz`
  - `peak_bin = bins[np.argmax(psd_db[bins])]`
  - `peak_dbm = float(psd_db[peak_bin])`
  - Power-weighted centroid: `weights = 10**(psd_db[bins]/10)`;
    `centroid_hz = float(np.sum(freqs * weights) / np.sum(weights))`
  - 3 dB bandwidth: bins where `psd_db[bin] >= peak_dbm - 3.0`;
    `bw_hz = float(len(bw_bins) * bin_width_hz)` (minimum 1 bin)
  - Yield tuple: `(centroid_hz, bw_hz, peak_dbm, noise_dbm)` where noise_dbm
    is from the SpectrumStamped noise_floor_db passed in

**Part A — Persistence tracker state (add to __init__):**

```python
self._tracks: dict[int, dict] = {}  # id -> {center_hz, bw_hz, frames, absent}
```

**`_update_persistence(raw_detections)` method:**
- `raw_detections`: list of `(centroid_hz, bw_hz, peak_dbm, snr_db)` from _group_detections
- Matching rule: for each raw detection, find existing track where
  `abs(track.center_hz - det.centroid_hz) < 0.5 * max(track.bw_hz, det.bw_hz)`
  Take the closest match. If found: update center_hz to power-weighted mean
  (use peak_dbm as weight proxy), increment frames, reset absent=0.
  If not found: create new track with id=self._next_id, frames=1, absent=0;
  increment self._next_id.
- For existing tracks with no matching raw detection: increment track.absent.
  Remove track if track.absent >= persistence_decay param.
- Return list of confirmed RFDetection objects where track.frames >= persistence_n.

**`_spectrum_callback(msg: SpectrumStamped)` — wire everything together:**
```python
def _spectrum_callback(self, msg):
    self._pfa = self.get_parameter('pfa').value
    self._guard = int(self.get_parameter('guard_cells').value)
    self._train = int(self.get_parameter('train_cells').value)

    psd_db = np.array(msg.psd_db, dtype=np.float64)
    mask = self._ca_cfar(psd_db, self._guard, self._train, self._pfa)
    raw_dets = self._group_detections(
        mask, psd_db, msg.bin_width_hz, msg.center_frequency_hz, msg.noise_floor_db)
    confirmed = self._update_persistence(raw_dets)

    # Add classification
    for det in confirmed:
        det.classification = self._classify_band(
            det.center_frequency_hz, det.bandwidth_hz)

    # Build and publish RFDetectionArray
    arr_msg = RFDetectionArray()
    arr_msg.header.stamp = msg.header.stamp
    arr_msg.header.frame_id = msg.header.frame_id
    arr_msg.noise_floor_dbm = msg.noise_floor_db
    n_bins = len(psd_db)
    det_bins = int(np.sum(mask))
    arr_msg.occupancy_pct = float(det_bins / n_bins * 100.0) if n_bins > 0 else 0.0
    arr_msg.detections = confirmed
    self._detections_pub.publish(arr_msg)

    # Cache for rf_environment timer
    self._last_arr = arr_msg
```

**`_env_timer_callback()` — 1 Hz RFEnvironment:**
```python
def _env_timer_callback(self):
    if self._last_arr is None:
        return
    arr = self._last_arr
    env = RFEnvironment()
    env.header.stamp = self.get_clock().now().to_msg()
    env.header.frame_id = self.get_parameter('antenna_frame').value
    env.emitter_count = len(arr.detections)
    env.occupancy_pct = arr.occupancy_pct
    env.noise_floor_dbm = float(arr.noise_floor_dbm)
    if arr.detections:
        powers = [d.power_dbm for d in arr.detections]
        idx = int(np.argmax(powers))
        env.peak_power_dbm = powers[idx]
        env.peak_frequency_hz = arr.detections[idx].center_frequency_hz
    self._env_pub.publish(env)
```
