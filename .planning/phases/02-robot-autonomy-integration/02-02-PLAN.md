  <action>
    Create `hackrf_ros/sweep_action_node.py`. Do NOT import or inherit from sweep_node.py
    (that is a matplotlib display tool, not reusable). Write from scratch using the
    interfaces block above.

    **Class: SweepActionNode(Node)**

    Constructor:
    - Declare parameters: `driver_node_name` (default '/hackrf_node'),
      `default_step_hz` (default 20e6), `default_averaging` (default 4),
      `spectrum_timeout_s` (default 3.0)
    - Create RELIABLE subscription to /hackrf/spectrum (SpectrumStamped),
      depth=10, ReentrantCallbackGroup — stores latest message in self._latest_spectrum
      with a threading.Event() to signal new data
    - Create AsyncParametersClient targeting driver_node_name
    - Create ActionServer for Sweep on /hackrf/sweep with ReentrantCallbackGroup;
      goal_callback accepts all goals; cancel_callback accepts cancel
    - self._cancel_requested: threading.Event()
    - self._saved_center_freq: float | None = None

    **_plan_hops(freq_min, freq_max, sample_rate, step_hz):**
    - usable_bw = sample_rate * USABLE_BW_FRACTION (0.8)
    - effective_step = min(step_hz, usable_bw) if step_hz > 0 else usable_bw
    - Generate centers from freq_min + sample_rate/2 stepping by effective_step
      until center - sample_rate/2 >= freq_max. Clamp last hop so its upper edge
      does not exceed freq_max. Return list[float].

    **_tukey_weights(n, alpha=0.2):**
    - Pure numpy, no scipy dependency. Taper length = int(n * alpha / 2).
    - ramp_up = np.linspace(0, 1, taper_len); ramp_dn = np.linspace(1, 0, taper_len)
    - Return np.concatenate([ramp_up, np.ones(n - 2*taper_len), ramp_dn])

    **_blend_hop_into_composite(psd_db, center_hz, sample_rate, freq_min, bin_width,
                                  comp_linear, comp_weight):**
    - Convert psd_db → linear: psd_lin = 10**(psd_db / 10)
    - Trim EDGE_TRIM (410) bins from each side of the 4096-bin array
    - Compute trimmed_freqs for remaining bins
    - Apply _tukey_weights(len(trimmed), alpha=0.2) as blend weights
    - For each bin j: idx = int((trimmed_freqs[j] - freq_min) / bin_width)
      if 0 <= idx < len(comp_linear): add weighted linear value to comp_linear[idx],
      add weight to comp_weight[idx]

    **_finalize_composite(comp_linear, comp_weight, n_bins):**
    - valid = comp_weight > 0
    - result = np.full(n_bins, -100.0, dtype=np.float32)
    - result[valid] = 10 * np.log10(np.maximum(comp_linear[valid] / comp_weight[valid], 1e-20))
    - return result

    **_set_center_freq(freq_hz) → bool:**
    - Uses AsyncParametersClient. Call set_parameters([Parameter('center_frequency',
      Parameter.Type.DOUBLE, freq_hz)]). spin_until_future_complete with 5s timeout.
    - Returns True if successful, False otherwise. Logs error on failure.

    **_wait_for_spectrum(timeout_s) → SpectrumStamped | None:**
    - Clears self._spectrum_event, waits with timeout. Returns self._latest_spectrum
      if event fires within timeout, else None. Thread-safe via Event.

    **_execute_sweep(goal_handle) — async execute callback:**
    1. Extract goal fields; apply defaults for step_hz=0 and averaging=0
    2. Save current center_frequency: self._saved_center_freq = get_parameter on driver
       via AsyncParametersClient (or read from latest spectrum msg center_frequency_hz)
    3. Plan hops via _plan_hops
    4. n_bins = int((freq_max - freq_min) / bin_width) where bin_width = sample_rate / 4096
       (sample_rate read from latest spectrum message, or default 20e6)
    5. Init comp_linear = np.zeros(n_bins), comp_weight = np.zeros(n_bins)
    6. self._cancel_requested.clear()
    7. For each hop i, center in enumerate(hops):
       a. Check goal_handle.is_cancel_requested: if True, break
       b. _set_center_freq(center) — log WARN on failure, continue
       c. Sleep 0.025s for PLL settle + flush (driver handles flush internally)
       d. Collect `averaging` spectrum messages: loop calling _wait_for_spectrum;
          accumulate psd_db arrays in linear domain; average when count reached
       e. Call _blend_hop_into_composite with averaged psd
       f. Publish feedback: current_hop=i+1, total_hops=len(hops),
          current_freq_hz=center, partial_psd_db=_finalize_composite(current state)
    8. Restore saved center freq via _set_center_freq(self._saved_center_freq)
    9. If goal was cancelled (is_cancel_requested was True):
       - If hops_done >= 1: set goal_handle.canceled(), return partial result with
         success=False, message='Cancelled — partial result'
       - Else: set goal_handle.canceled(), return empty result
    10. goal_handle.succeed(); return result with success=True, stitched psd_db

    **main():**
    ```python
    rclpy.init(args=args)
    node = SweepActionNode()
    executor = MultiThreadedExecutor()
    executor.add_node(node)
    try:
        executor.spin()
    except KeyboardInterrupt:
        pass
    finally:
        executor.shutdown()
        node.destroy_node()
        rclpy.try_shutdown()
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Action client → SweepActionNode | Goal fields from any ROS2 node (untrusted caller) |
| SweepActionNode → /hackrf_node param client | Parameter write to hardware driver |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Tampering | freq_min_hz / freq_max_hz goal fields | mitigate | Validate in _execute_sweep: freq_max > freq_min, both within HackRF range (1 MHz–6 GHz); abort goal with failure message if out of range |
| T-02-02-02 | Denial of Service | averaging=0 or very large averaging in goal | mitigate | Clamp averaging to min=1, max=64 in _execute_sweep before collecting spectra |
| T-02-02-03 | Denial of Service | step_hz extremely small (millions of hops) | mitigate | Compute n_hops before starting; if n_hops > 500, abort goal with descriptive error |
| T-02-02-04 | Tampering | center_frequency parameter restored on cancel | accept | Restore is best-effort; if driver node is down, WARN is logged; radio remains at last hop freq until next user action — acceptable for robot autonomy use case |
| T-02-02-05 | Elevation of Privilege | AsyncParametersClient sets arbitrary params | accept | Scope limited to center_frequency restore; no other params written by this node |
</threat_model>
