<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pip install → runtime | sigmf package from PyPI; malicious package unlikely but dependency pinning absent |
| rosidl generation → binaries | Generated C++ code compiled into shared libraries; no untrusted input at this stage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | sigmf PyPI package | accept | Package is well-known (sigmf/sigmf-python on GitHub); no sensitive data at build time; pin version in follow-up hardening phase |
| T-02-01-02 | Information Disclosure | action/RecordIQ.action — output_path field | mitigate | output_path validated in iq_recorder_node (02-03) to reject path traversal; interface itself is neutral |
| T-02-01-03 | Denial of Service | Large psd_db float32[] in Sweep result | accept | DDS message size bounded by sweep range / bin_width; typical max ~4000 floats (~16 KB); within CycloneDDS defaults |
</threat_model>
