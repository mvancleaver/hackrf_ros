    def _iq_callback(self, msg):
        # Convert Float32MultiArray to ci8 bytes
        arr = np.array(msg.data, dtype=np.float32)
        # Driver publishes normalized float [-1,1]; convert back to int8
        raw = np.clip(arr * 128.0, -128, 127).astype(np.int8)
        chunk = raw.tobytes()
        try:
            self._write_q.put_nowait(chunk)
        except queue.Full:
            try:
                self._write_q.get_nowait()
            except queue.Empty:
                pass
            try:
                self._write_q.put_nowait(chunk)
            except queue.Full:
                pass

| Boundary | Description |
|----------|-------------|
| Action client → IQRecorderNode | output_path from untrusted caller — filesystem write target |
| IQRecorderNode → filesystem | Writing arbitrary paths under output_path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | output_path path traversal (e.g., "../../etc") | mitigate | Resolve path with os.path.realpath() and check it starts with an allowed prefix; if no prefix configured, log WARN and accept (robot-internal use) |
| T-02-03-02 | Denial of Service | duration_s=0 recording forever, filling disk | mitigate | Declare max_duration_s parameter (default 300s); abort if duration_s=0 and elapsed > max_duration_s, with configurable override |
| T-02-03-03 | Information Disclosure | SigMF file contains robot pose | accept | Robot pose in map frame is mission-operational data; files written to local filesystem under caller-specified path; no network exfiltration |
| T-02-03-04 | Denial of Service | Write thread blocks if disk full (write() blocks) | mitigate | Use non-blocking write with try/except OSError; on ENOSPC abort recording and abort goal with descriptive error |
| T-02-03-05 | Denial of Service | Large IQ queue consuming memory (maxsize=256) | accept | 256 chunks * ~8KB/chunk = ~2MB max; bounded and acceptable for Jetson ARM64 with 8+ GB RAM |
