  <implementation>
    Create hackrf_ros/tx_controller.py with:

    Module-level custom exceptions:
    - TXBlockedError(Exception): antenna not confirmed
    - TXFreqBlockedError(Exception): frequency on restricted band (filter-gated)
    - TXHardBlockedError(Exception): frequency is always-blocked — NO bypass path exists
    - TXNotAuthorizedError(Exception): no valid auth token

    Module-level Lua script constant _LUA_GETDEL (per RESEARCH.md Pattern 1).

    TXController class:
    - ALWAYS_BLOCKED_BANDS: class constant — bands that are HARD-BLOCKED regardless of filter settings.
      These are checked UNCONDITIONALLY and raise TXHardBlockedError with no bypass:
        (406_000_000, 406_100_000),   # EPIRB distress — international law prohibition
        (1_090_000_000, 1_090_000_001),  # ADS-B 1090ES — aviation safety, no bypass
      Rationale: Both appear in RESTRICTED_BANDS too, but that check is gated by _freq_filter_active().
      ALWAYS_BLOCKED_BANDS ensures these two are blocked even when the filter is fully disabled.

    - RESTRICTED_BANDS: list of (min_hz, max_hz) tuples per D-04 / RESEARCH.md exact values
      (filter-gated — only enforced when _freq_filter_active() is True):
        (108_000_000, 137_000_000),   # Aviation VHF
        (150_000_000, 174_000_000),   # Emergency/public safety
        (406_000_000, 406_100_000),   # EPIRB distress (also in ALWAYS_BLOCKED_BANDS)
        (450_000_000, 470_000_000),   # Emergency/public safety UHF
        (700_000_000, 900_000_000),   # Cellular LTE
        (960_000_000, 1_215_000_000), # Aviation DME/TACAN
        (1_030_000_000, 1_030_000_001),  # ATC Mode C exact
        (1_090_000_000, 1_090_000_001),  # ATC Mode S exact (also in ALWAYS_BLOCKED_BANDS)
        (1_164_000_000, 1_215_000_000),  # GPS L5
        (1_559_000_000, 1_610_000_000),  # GPS L1/L2
        (1_700_000_000, 2_100_000_000),  # Cellular AWS/PCS
        (2_500_000_000, 2_700_000_000),  # Cellular Band 41
    - AUTH_KEY = 'hackrf:tx:auth'
    - ANTENNA_KEY = 'hackrf:tx:antenna_confirmed'
    - FREQ_OVERRIDE_KEY = 'hackrf:tx:freq_filter_override'
    - IQ_DATA_KEY = 'hackrf:tx:iq_data'

    __init__(self, node, redis_client, logger):
        Store references. Set _antenna_confirmed=False, _is_transmitting=False.
        _tx_lock = threading.Lock() (not RLock — TX cannot re-enter itself).

    open(self) -> None:
        Read antenna confirmation per D-07/D-08 (RESEARCH.md Pattern 4):
        1. If node.get_parameter('tx_skip_antenna_check').bool_value is True:
             _antenna_confirmed = True; log WARNING about bypass
        2. Else: check Redis key ANTENNA_KEY; set _antenna_confirmed accordingly

    stop(self) -> None:
        Alias for stop_tx(). Called from destroy_node — must be safe to call any time.

    start_tx(self, freq_hz: int, auth_token: str, iq_bytes: bytes, txvga_gain: int = 0) -> None:
        Guards in ORDER — hard-block runs BEFORE filter-gated check and BEFORE token consumption:
        1. if not _antenna_confirmed: raise TXBlockedError
        2. if _is_hard_blocked(freq_hz): raise TXHardBlockedError  # NO bypass, NO token consumed
        3. if _freq_filter_active() and _is_freq_restricted(freq_hz): raise TXFreqBlockedError
        4. if not _consume_auth_token(freq_hz, auth_token): raise TXNotAuthorizedError
        5. Acquire _tx_lock:
           a. node._stop_rx_if_running()
           b. time.sleep(0.1)  # firmware settle per libhackrf #916
           c. hackrf = node._hackrf (read under _device_lock in caller, but TX uses node ref)
           d. with node._device_lock:
                hackrf.center_freq = freq_hz
                hackrf.txvga_gain = txvga_gain
                hackrf.buffer = bytearray(iq_bytes)
                hackrf.start_tx()
           e. _is_transmitting = True
           f. Log AUDIT: TX started freq={freq_hz} token_hint={auth_token[:8]}... iq_len={len(iq_bytes)}

    stop_tx(self) -> None:
        Per RESEARCH.md Pattern 3:
        with _tx_lock:
            if not _is_transmitting: return
            try: node._hackrf.stop_tx() except RuntimeError: pass
            _is_transmitting = False
            time.sleep(0.1)  # settle before RX resume
            node._start_rx_if_stopped()
            log info: TX stopped; RX resumed.

    _is_hard_blocked(self, freq_hz: int) -> bool:
        Return True if freq_hz falls within any band in ALWAYS_BLOCKED_BANDS.
        Same range check as _is_freq_restricted but uses ALWAYS_BLOCKED_BANDS constant.
        This check is unconditional — the filter enable flag is irrelevant.

    _is_freq_restricted(self, freq_hz: int) -> bool:
        Per RESEARCH.md Pattern 5. Checks RESTRICTED_BANDS.

    _freq_filter_active(self) -> bool:
        Per RESEARCH.md Pattern 5 — dual-disable model (D-05).

    _consume_auth_token(self, expected_token: str) -> bool:
        Per RESEARCH.md Option 1 — try native getdel first, fall back to Lua.
