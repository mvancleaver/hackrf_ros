<objective>
Create the `hackrf_driver` package scaffold: move RedisBridge and TXController out of hackrf_ros, decouple TXController from the rclpy node reference, create config.py with PARAM_RANGES, and migrate all 36 related unit tests.

Purpose: hackrf_driver must have no rclpy import. TXController currently takes `node` and calls `node.get_parameter(...)`, `node._hackrf`, `node._device_lock`, `node._stop_rx_if_running()`, `node._start_rx_if_stopped()`. These must be replaced with primitive arguments so TXController can be tested and run without ROS2.

Output: hackrf_driver/ package with decoupled tx_controller.py, redis_bridge.py, config.py, and 36 passing tests. No driver main loop yet (that is Plan 03).
</objective>
