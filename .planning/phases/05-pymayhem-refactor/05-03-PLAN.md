    HackRFDriver.__init__(config: dict) behavior:
    - Stores config dict (from load_config or CLI overrides)
    - Creates self._logger = logging.getLogger('hackrf_driver')
    - Creates dual queue.Queue(maxsize=64): self._ros_queue, self._redis_queue
    - Creates self._stop_event = threading.Event()
    - Creates self._device_lock = threading.RLock()
    - Creates self._hackrf = None, self.is_hackrf_streaming = False
    - Creates self._last_params dict from config (center_frequency, sample_rate, lna_gain, vga_gain, amp_enabled)
    - Creates self._mayhem = MayhemClient(config.get('serial_port', '/dev/hackrf_mayhem'))
    - Creates self._redis_bridge = RedisBridge(self._redis_queue, self, self._logger, maxlen=config.get('redis_stream_maxlen', 10000))
    - Opens redis_bridge; if open() returns False logs warning and continues (graceful degradation)
    - Creates and opens TXController with primitive args (see interface block above)
    - Registers SIGINT/SIGTERM handlers
    - Calls self._try_connect() to attempt pyhackrf2 connection
    - Starts IQ publish daemon thread
    - Calls self._mayhem.open() (serial connection)

    HackRFDriver exposes same method names as HackRFNode for RedisBridge dispatch compatibility:
    - _set_center_frequency(freq_hz), _set_sample_rate(sr), _set_lna_gain(lna), _set_vga_gain(vga), _set_amp_enabled(enabled)
    - _start_rx_if_stopped(), _stop_rx_if_running()
    - _build_state_dict() -> dict (same fields as HackRFNode._build_state_dict, minus ROS-specific fields)
    - _mayhem attribute (for redis_bridge dispatch: node._mayhem.appstart(app))

    shutdown() behavior:
    - Stops TX first (self._tx_controller.stop())
    - Closes redis_bridge
    - Closes mayhem serial
    - Stops pyhackrf2 (same pattern as destroy_node)
    - Sets self._stop_event (unblocks run())

    Parameter update flow (replaces ROS2 set_parameters):
    - _update_param(name, value): validates against PARAM_RANGES, updates self._last_params[name], calls _configure_device() if hackrf connected

    _try_connect() / _reconnect_callback() / exponential backoff: exact port from HackRFNode using threading.Timer instead of self.create_timer().

    - test_set_methods_call_update_param: _set_center_frequency calls _update_param

         ```python
             parser.add_argument('--lna-gain', type=int, default=None, dest='lna_gain')
             parser.add_argument('--vga-gain', type=int, default=None, dest='vga_gain')
             parser.add_argument('--sample-rate', type=float, default=None, dest='sample_rate')
             parser.add_argument('--serial-port', default=None, dest='serial_port')
             parser.add_argument('--redis-host', default=None, dest='redis_host')
             parser.add_argument('--redis-port', type=int, default=None, dest='redis_port')
             parser.add_argument('--no-freq-filter', action='store_true', dest='no_freq_filter')
             parser.add_argument('--skip-antenna-check', action='store_true', dest='skip_antenna_check')
             args = parser.parse_args()

             config = load_config(args.config or '')
             # CLI overrides
             if args.freq is not None:
                 config['center_frequency'] = args.freq
             if args.lna_gain is not None:
                 config['lna_gain'] = args.lna_gain
             if args.vga_gain is not None:
                 config['vga_gain'] = args.vga_gain
             if args.sample_rate is not None:
                 config['sample_rate'] = args.sample_rate
             if args.serial_port is not None:
                 config['serial_port'] = args.serial_port
             if args.redis_host is not None:
                 config['redis_host'] = args.redis_host
             if args.redis_port is not None:
                 config['redis_port'] = args.redis_port
             if args.no_freq_filter:
                 config['tx_freq_filter_enabled'] = False
             if args.skip_antenna_check:
                 config['tx_skip_antenna_check'] = True

             driver = HackRFDriver(config)
             driver.run()
         ```
