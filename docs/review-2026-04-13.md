# hackrf_ros Code Review — 2026-04-13

Three specialist reviewers examined the package: RF/signal-processing, embedded-Linux/real-time, and
ROS2 architecture. Findings are severity-classified (CRITICAL / HIGH / MEDIUM / LOW).
Status column added after fixes applied.

## Architecture Limitations (Not Bugs)

- **Single-antenna RSSI-only localization**: Emitter localization requires robot movement to collect spatially diverse observations. A stationary robot cannot produce a position estimate. RSSI accuracy is ±3–10 m in typical indoor environments due to multipath and shadowing — not reflected in the covariance field.
- **20 MHz instantaneous bandwidth**: Wideband coverage requires frequency sweeping. During a sweep, continuous PSD publishing is suspended.
- **8-bit ADC dynamic range**: ~50 dB usable range. Strong out-of-band signals will degrade sensitivity for in-band signals.
- **Per-detection cyclo classification requires DDC**: Current implementation applies one classifier result to all ISM-band detections simultaneously. Correct per-detection classification requires mixing each detection to baseband and filtering before classification — not yet implemented.
